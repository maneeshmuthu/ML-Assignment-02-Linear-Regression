# California Housing Regression Assignment

This project implements multiple regression algorithms on the California Housing dataset using Python and Scikit-learn.

## Algorithms Used
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- Gradient Boosting Regressor
- Support Vector Regressor (SVR)

## Evaluation Metrics
- Mean Squared Error (MSE)
- Mean Absolute Error (MAE)
- R² Score

## Tools Used
- Python
- Pandas
- Scikit-learn
- Jupyter Notebook
